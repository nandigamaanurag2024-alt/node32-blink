# NodeMCU Blink Project

## Objective
Learn PlatformIO and embedded development by uploading a blink program.

## Hardware
- NodeMCU ESP8266 (ESP-12E)
- Micro USB cable
- MacBook Air M1

## Software
- VS Code
- PlatformIO
- Git
- GitHub

## Result
Successfully compiled and uploaded a blink program to the NodeMCU board. The project was committed and pushed to GitHub.
